# 桌面连续改选与连线修复

0.11.1 在草稿中读到第一个 SVG 引用后会拒绝改选。0.12.0 以宿主的结构化草稿为准，连续点选只替换插件自己的引用。卡片、线上的高亮与发给模型的目标读取同一份草稿。

在 macOS 的 DeepSeek Harness Desktop、`deepseek-account/deepseek-flash` 和 0.12.0 插件上，用工作区原有的「软件开发迭代闭环.svg」进行了以下复验。

1. 在单独会话打开原图。预览中有 6 张卡片和 6 条业务连线，底部图例中的两支箭头没有进入选区列表。
2. 先写下修改要求，依次点击「需求分析」「编码实现」和橙色回流虚线的笔画。每次只高亮最新目标，输入框中只有一张选区卡片，先写的要求一直保留。
3. 完整退出并重启桌面应用。恢复的草稿仍指向「迭代复盘 → 需求分析」。实测升级时前端可以先于模型工具更新，完整退出会同时重载后端。
4. 发送「保留起点，将终点改到方案设计」。宿主日志记录一次 `svg_artwork reconnect`，目标为 `at:37`，起点 `node-06-retro`，新终点 `node-02-design`。该轮桌面显示 14 秒。
5. 对照原图和新文件「回流改选验收.svg」，只有回流线的 `d` 属性发生变化。新路径为 `M 900 740 L 605 740 L 605 560`，终点在「方案设计」卡片底边。6 张卡片、其余 5 条线、虚线样式和箭头标记均保留。「下一轮迭代」是独立文本，仍在原位。

自动回归还覆盖同名节点、跨文件改选、用户手输的相似文本、独立引用及文件引用的位置、输入被锁定、旧几何失效和匿名路径重复。原生 K/V 分叉的主干、箭头和分支都定位到同一个逻辑边。用于自由绘图的自动重连支持独立终端箭头和可核验的节点坐标，分离绘制的箭头可通过线段选区定位后进一步处理。[草稿回归](../../apps/dsh-plugin/client/selection.test.mjs) · [几何回归](../../apps/dsh-plugin/test/artworkEdges.test.ts)

## 单条连线的编辑方案与 0.13.0 实测

| 设计决定               | 用户操作及实现                                                                                                                                                                                                                 |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 一次编辑绑定一条线     | 普通点选可随时换目标。选中线后显示起点、终点和线型。只有按下端点按钮后，下一次点击卡片才会把卡片指定为该线的新端点。                                                                                                           |
| 原始选区与待修改值分开 | 草稿保存原文件、边标识和原几何。用户的三个修改分别写入 `changes.from`、`changes.to`、`changes.connectorStyle`，可以单独使用或一起发送。另选一条线会清除前一条线的待修改值。                                                    |
| 发送后另存并读回       | 原生图使用 `svg_edit_flowchart reconnect`；自由 SVG 使用 `svg_artwork reconnect`，先匹配原几何。两者复用已有的避障和曲线算法。显式要求弧线时必须得到一段二次曲线；显式要求直线时必须得到一段可通行的直线。无法满足就返回原因。 |
| 保留图上的其他元素     | 原生图独立验证边的起点、终点及其余节点和边。自由 SVG 局部改写选中元素，必要时把直线元素换成路径以容纳弯曲，保留箭头标记和描边；另存后核对原文件及结果。                                                                        |

在同一张迭代闭环图的桌面预览里，点击原来竖直向下的「发布上线 → 迭代复盘」。用「起点」按钮点选「编码实现」，用「终点」按钮点选「方案设计」，在线型菜单选择「弧线」。发给 Flash 的自然语言仅要求按选区设置另存，两个节点 ID 和线型来自图上的操作。模型一次调用重连工具，随后读回，桌面显示整轮 19 秒。

磁盘上，原来的 `M 1670 560 V 672` 变为 `M 815 450 Q 782.5 470.8 750 450`。它从「编码实现」的左边指向「方案设计」的右边，控制点偏离两端所在的水平线，箭头改随曲线末端方向。新旧文件仅这一处路径值不同。原图里的「方案设计 → 编码实现」直线仍在，所以修改后的两张卡片之间可以同时看到相反方向的一直一弯两条线。
