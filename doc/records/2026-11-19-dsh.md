# DSH 插件卸载验收

2026-11-19，关联 #4、#16。

首次验收尝试按 patch 中的 ID 从根 loader 移除插件。真实的 `sdk-minimal` profile 已经能生成和检查 SVG，但这个 ID 位于 bundle 挂载的子树内，根 loader 未找到它。仅删除配置并重启也无法证明当前进程已释放工具注册。

验收驱动现在通过 Cordis loader 枚举实际加载项，按包名找到实例，释放该实例后等待生命周期完成，再从工具注册表查询两个名称。随后从 profile 卸载安装包，启动新进程，再次读取注册表。两次查询都返回空数组。该逻辑位于验收驱动，插件本身只通过 DSH 工具服务注册。[验收驱动](../../apps/dsh-plugin/verification/probe.mjs) · [实际运行结果](../evidence/dsh/install/verification.json)
