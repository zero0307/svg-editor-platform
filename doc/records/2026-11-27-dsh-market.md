# 0.14.2 市场候选的无插件对照

2026-11-27 在 macOS 上运行 DeepSeek Harness 0.2.2-rc.5。四项任务各用同一份输入、相同中文提示、相同账号模型、独立工作目录和新会话。两组的标准工具、工作区写权限和账号配置相同，工具清单相差一个 SVG bundle。所有会话的请求记录都指向 `deepseek-account/deepseek-flash`。两组均得到目标 ID。之后对三个可点选目标加测第三组，在相同提示末尾附上该版本桌面客户端 `quoteNode` 生成的选区。对话通过真实 headless 宿主执行，点选交互另由 Chrome 的 27 项断言覆盖。每种条件每题运行一次，单轮上限 200 秒。

| 任务                     | 无 SVG 插件               | 装插件，由模型自由选择工具  | 装插件，附桌面选区        |
| ------------------------ | ------------------------- | --------------------------- | ------------------------- |
| 编码器同名框改名         | 通过，37.14 秒 / 131,717  | 通过，23.01 秒 / 90,192     | 通过，9.47 秒 / 37,364    |
| 交叉注意力仅改标题       | 通过，25.56 秒 / 63,986   | 通过，20.39 秒 / 95,231     | 通过，10.82 秒 / 38,427   |
| 近距离平行线改接并避交叉 | 200 秒超时                | 200 秒超时                  | 通过，102.62 秒 / 368,647 |
| Transformer K/V 共用主干 | 通过，187.68 秒 / 976,153 | 通过，175.23 秒 / 2,241,415 | 未测                      |

每格为整轮墙钟时间与宿主报告的总 token，包含缓存读取。超时轮未取得完整用量。各轮按顺序运行；缓存、服务负载和模型选工具均会影响读数。改名通过要求仅指定标题改变、原件保留，另验预期文件逐字节相等。改线核对端点、箭头、曲线及邻线横穿。K/V 检查源头接点、共用主干、分别可达的两个箭头、K/V 标签以及其余分组。无插件使用 path 绘制的直线段也按相同几何计分。完整提示、输入摘要、产物摘要、实际工具调用、用量及逐轮验收结果见[原始数据](../evidence/dsh/market-0.14.2/results.json)。

在近邻线任务中，无插件到时没有输出。只安装插件并使用自然语言的会话到时留下了一条仍横穿邻线的弧线。附上选区后，模型写出了通过独立几何校验的弧线，其他元素保持原样。K/V 任务上无插件也能画对，安装插件后读回与反复检查增加了总 token。简单改名同样可由两组完成；其中一轮装插件的模型全程只用了通用工具。
