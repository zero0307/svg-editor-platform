保留原 CLI 的原子保存策略时，代码检查发现旧实现把 UUID 接在目标文件名后面。一个合法的长文件名会因此产生过长的临时文件名。宿主改为在同目录排他创建固定长度的随机文件，关闭后再 rename。只有创建成功的调用才负责失败清理。真实文件系统测试使用 220 字符的名称主体并发写入，核对读回的完整版本、失败替换保留的目录内容和临时文件清理结果。[I/O 实现](../../packages/host/src/LocalFileStore.ts) · [异常路径测试](../../packages/host/test/io.test.ts)

`npm test -w @svgframe/host` 可以单独复验这一板块。POSIX FIFO 与悬空文件链接用例适用于 macOS/Linux，Windows 上的目录链接另由 junction 用例覆盖。完整的 dir 命令回显、排序和历史断言由 #18 接入。[后续分工](../tasks/index.md#本轮基建之后的分工)
