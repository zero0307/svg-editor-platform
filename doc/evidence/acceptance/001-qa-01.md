## 4. 实际执行的命令与真实结果

```bash
# 1) 从 final 导出隔离树（不建 worktree，不动 refs）
git archive --format=tar -o artifacts/baseline/final.tar 'final^{commit}'
mkdir -p artifacts/baseline/final-tree && tar -xf artifacts/baseline/final.tar -C artifacts/baseline/final-tree

# 2) 在隔离树安装锁文件依赖并构建（.npmrc 的 cache 为仓库内相对路径，必须显式指定）
cd artifacts/baseline/final-tree
npm ci --cache E:\develop\svg-editor-platform\.npm-cache --prefer-offline   # exit 0，added 8 packages
./node_modules/.bin/tsc -p tsconfig.json                                    # exit 0

# 3) 生成 golden 与证据
cd ../../..
node scripts/baseline/record.mjs \
  --entry artifacts/baseline/final-tree/dist/src/bootstrap/main.js \
  --tag final --update --evidence doc/evidence/baseline \
  --install-method "npm ci --cache .npm-cache --prefer-offline"
# exit 0；basic=1/flowchart=0/io=1/dir=1

# 4) 回放比较：(a) final 树自身 (b) 当前工作树构建
node scripts/baseline/compare.mjs --entry artifacts/baseline/final-tree/dist/src/bootstrap/main.js
node scripts/baseline/compare.mjs --entry dist/src/bootstrap/main.js
# 两次均：4 sessions, 4 matched, 0 differed，exit 0

# 5) 根检查
npm test          # 89 tests / 89 pass / 0 fail（原 83 项 + 新增 6 项）
npm run check     # exit 0（format、docs、测试、架构检查）
```

关键数字与结论：

- `final` 标签对象 `25c263bda5515816d59efb383a3790dd2c77df3a`，解引用提交 `e5621a68afd4731626d54566f17ba55885d1bc0f`；golden 来自该提交的构建产物，未使用当前工作树生成。
- 四会话真实退出码：`basic=1`、`flowchart=0`、`io=1`、`dir=1`；stdout 字节数 1177 / 824 / 643 / 65，stderr 均为 0 字节。
- 逐字节比较：final 树回放与当前构建回放都是 4/4 匹配、0 差异；比较不 trim、不排序、不删除 warning/error，并同时比较退出码与保存产物（`demo.svg`、`flowchart.svg`、`other.svg`、`saved.svg`）。
- 规格差异：7 处记录在 [spec-diff.md](../baseline/spec-diff.md)，裁决均为“以 `final` 实际输出为 BASE-01 基准，不改实现”，其中 banner 版本、提示符、tree 列对齐、move/undo 文案差异已逐条列出。
