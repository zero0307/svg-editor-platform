## 3. 输出格式与策略（实测）

固定夹具 `test/fixtures/dir/tree`（`dir` 无文档，A 默认入口）：

```text
[DIR]  sub-one
[DIR]  sub-two
[FILE]  .hidden
[FILE]  Zeta.md
[FILE]  alpha.txt
[FILE]  with space.txt
[FILE]  中文名.txt
```

真实临时目录（中文名、空格、隐藏项、子目录）：

```text
[DIR]  sub-one
[DIR]  中文 目录
[FILE]  .hidden
[FILE]  Zeta.md
[FILE]  alpha.txt
[FILE]  with space.txt
```

- 组序：目录 → 普通文件 → 链接 → 其他；组内按 `a < b` 的大小写敏感 JS 字符串序；标记后两个空格；含隐藏项、不递归、不跟随链接；空目录 `(empty directory)`；失败输出 `error: cannot read directory: <path>`（`path` 为 `cwd()`）。
- 无参数；多余参数按最保守 Phase 1 约定输出 `error: usage: dir`。
- 排序、标记、空目录与错误传播全部由插件负责；host 只提供端口。

## 6. 差距与后续

1. **dirty 状态暂无框架 API**：`#20`（modified-star）才引入 dirty；本节点证明 `dir` 为 `query`，不触发事件、不调用 session、不改文档/历史/屏障，因此不可能改变 dirty 基准，待 `#20` 后组合级复核。
2. **符号链接未在本机实际创建**：Windows 未授予符号链接权限，根测试在 `symlink` 抛错时以诊断跳过真实链接断言；`[LINK]`/`[OTHER]` 的渲染与组序由 `FakeDirectoryReader` 替身用例覆盖，真实链接行为需在允许的平台上补验。
3. **C_A/C_B 证据分支未建立**：本节点在同一提交内验证 A/B 注册表与同一夹具输出一致；课程要求的独立 `C_A`/`C_B` 差异证据由 `#21` 统一建立。
4. `doc/transcript/stats-dir.txt` 已提供命令输入；其固定期望输出（含目录夹具）由 `#21` 在 A/B 回放中生成并归档，本节点不手填期望输出。
5. 仅本机 Windows + Node v26.13.0 实跑；未在 Node 22/24、Linux/macOS 或 CI 执行；`npm run verify:visual` 与本节点无关，未重跑。
