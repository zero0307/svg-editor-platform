## 2. 交付范围

- `scripts/metrics/metrics.mjs`：`--from/--to/--out` 参数，只读 Git 提交对象生成指标与产物。
- `scripts/metrics/rules.mjs`：`RULES_VERSION = 1` 的行数与圈复杂度规则，基于 TypeScript 语法树。
- `scripts/metrics/ast.mjs`：`typescript/unstable/sync` 仅语法解析（临时目录落盘 + 最小 tsconfig）。
- `scripts/metrics/git.mjs`：`rev-parse` / `ls-tree` / `show` 的只读读取。
- `scripts/metrics/classify.mjs`：glob 匹配、先排除后分类、每文件恰好一条、遗漏/重复失败。
- `scripts/metrics/classification.json`：内核／装配处／插件三类 + VSCode／DSH 单列的路径职责表。
- `scripts/metrics/migration.json`：旧路径 → 新路径、分类变化与说明，按两端检测 `moved`/`pending`/`both`/`neither`。
- `scripts/metrics/rules.test.mjs`：10 项测试（逐项复杂度、注释/字符串、行数、嵌套、成员、分类失败、当前树完整、两次运行一致）。
- `docs/metrics/`：首版框架候选产物（`e5621a6-to-17f9a78.json`、`summary.md`）与重算说明。
- 文档：`scripts/metrics/README.md`、`docs/metrics/README.md`、[ADR-0016](../../adr/0016-metrics-rules-and-classification.md)（Proposed）、`doc/maintenance.md`、`doc/architecture.md` §13、`doc/acceptance.md` 指标状态句。
- 生成物排除：`.prettierignore` 增加 `docs/metrics/*.json`、`docs/metrics/summary.md`，保证脚本重跑字节不被格式化改变。

未改动 `src/`、`test/` 既有断言、`packages/`、`apps/`。

## 6. 差距与后续

1. `plugin` 类为 0 是当前事实：`packages/builtins`、`apps/cli`、`plugins/*` 尚未落地；`#15` 冻结框架、`#22` 打 `p2` 前必须重跑，终版指标不能用本记录冒充。
2. `p2` 尚不存在，验收第 4 条只验证了“可重跑”机制；“在 p2 上重跑并核对 CLI 源码文件集合与散列”留给 `#22`。
3. 指标测试未接入根 `npm run check`（根 `npm test` 只跑 `dist/test`）；是否纳入 CI 由 `#15` 决定，当前需手动执行 `node --test scripts/metrics/rules.test.mjs`。
4. 只在 Windows + Node v26.13.0 实测；依赖 `@typescript/typescript-<platform>` 原生包，其他平台未验证。
5. 每个被测文件一次 `git show`，当前秒级；未改用 `cat-file --batch`。
6. `typescript/unstable/sync` 属实验入口，升级 TypeScript 时可能变化，需按 ADR-0016 重新核对。
