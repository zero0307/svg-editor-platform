# ADR-0006 DSH 的可选二次曲线路径

状态为 Proposed，关联 #16。

调用方可选择整图线型并按边 ID 覆盖。圆角保留端点和已得到的避障折线。弧线候选以二次贝塞尔凸包细分验证与障碍的间隙，空间不足则使用圆角或既有折线。每个曲线片段是独立的 SVG `path`，每个箭头保留两翼。箭头方向使用末段切线，文件读回基于实际几何。节点形状支持矩形和椭圆，端点使用各自的轮廓。

会话可显式装配仅识别绝对 `M x y Q cx cy x y` 路径的图形工厂。平移、统一缩放和克隆保留控制点，其他路径命令产生明确的导入错误。旧 CLI 使用原有工厂。可选绘制属性允许透明填充 `none` 和由 2 至 8 个正整数构成的描边虚线模式，真实会话与替身共用校验。选择默认折线可继续向 Phase 1 导出。分区标题与节点色阶只影响外观。
