## 单篇模板

```markdown
# ADR-NNN 标题

状态：Proposed / Accepted / Superseded
日期：YYYY-MM-DD
关联：Issue、PR、需求条目

## 背景

实际问题、课程约束和变化点。

## 决策

公开接口、调用顺序、失败与恢复行为。

## 备选与取舍

考虑过的方案，选择理由和承担的代价。

## 验证

对应测试、反例、证据路径和最终代码位置。

## 后续

需要调整的条件；如被替代，链接后继ADR。
```
