# ADR-0005 通过会话设置图形与文字的绘制属性

状态为 Proposed，随 DSH 0.4.0 评审。关联 #16、DSH-01。

流程图需要可编辑的圆角矩形、居中文字和带颜色的箭头。由调用方在 `EditorSessionPort.create` 的可选 `presentation` 中声明单个 SVG 的绘制属性，编解码器继续处理标准图形。主题、节点角色、换行与绕线由 DSH 插件选择。旧调用可以继续只提供几何参数。将样式直接拼入最终 XML 会绕开会话契约，也会使测试替身与真实保存路径的结果分叉。

契约列出支持的属性和对应字面值。真实会话和替身在插入图形前做相同的校验，失败时保持原状态。矩形与文字分别存储几何与绘制属性，描边宽度等已有领域字段通过编辑接口赋值。端点关系和多行文字的分隔信息仍使用 ADR-0004 的数据属性。编辑单个文字元素后，读回会按顺序重组当前文字。
